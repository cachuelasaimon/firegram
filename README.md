## Setting up
1. Initialize Cloud Firestore: Create your own firebase firestore database and copy the project credentials [Initializing a firestore project](https://firebase.google.com/docs/firestore/quickstart)

2. go to `src/firebase/config.ts` and replace the `firebaseConfig` variable with the one generated after the first step and you should be good to go!
